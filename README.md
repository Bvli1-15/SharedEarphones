# 共享耳机 · SillyTavern 音乐播放器

播放器本体：悬浮球、卡片、歌词、歌单、背面耳机线，导入时自动配歌词和封面。
让 char 听见、自动标签、char 切歌是后面几步。

需要 SillyTavern 1.12 或更新的版本。

## 安装

**方法一：粘贴地址安装（推荐）**

在酒馆扩展面板点「安装扩展」，粘贴：

```
https://github.com/Bvli1-15/SharedEarphones
```

以后有新版，在「管理扩展」里点更新就行。跑酒馆的机器需要装有 git（Termux 里没有的话执行 `pkg install git`）。

仓库是私有的，地址里要带上 GitHub token（在 Settings → Developer settings 里生成，只给这个仓库的读权限就够）：

```
https://你的token@github.com/Bvli1-15/SharedEarphones
```

**方法二：手动放文件夹**

1. 把仓库下载下来，得到 `SharedEarphones` 文件夹。
2. 放到 `SillyTavern/data/default-user/extensions/` 下面（多用户的话把 `default-user` 换成你的用户名）。
   - 手机 Termux 一般是 `~/SillyTavern/data/default-user/extensions/`。
3. 刷新酒馆页面。扩展面板里会出现「共享耳机」。

## 用法

- 点悬浮球：卡片弹出来；再点一下收回。球可以拖到任何地方，松手会记住位置。
- 左下星星：歌单。导入歌曲、导入歌词、切换播放模式、新建歌单都在这里。
  - 导入歌曲有五种方式：
    - **流行歌**：按歌名、歌手搜网易云等平台的歌（来自 GD音乐台），点 ＋ 加进歌库。只在线播放，不下载、不存音频，每次放的时候现取链接，所以没网时放不了。网易云搜不到的（比如周杰伦）可以点上面换成 JOOX 试试。对方限制 5 分钟 50 次请求，插件会自己数着。
    - **在线找歌**：搜开放授权的免费音乐（来自 Openverse，大多是 Jamendo 上独立音乐人的作品），能先试听，点 ＋ 收进歌库。曲库是英文的，搜索框下面有一排中文情绪词（钢琴、雨天、爵士、夜晚……）可以直接点。
    - **选文件**：可以多选。mp3、m4a、flac、wav、ogg/opus 都能读出歌名、歌手、封面；视频文件只取声音；把 .lrc 一起选上会自动配到同名的歌。
    - **压缩包**：整个文件夹打成 zip 一次导入，Windows 打的中文文件名也能认。
    - **粘贴链接**：音频文件的直链，一行一个。能下载的存进浏览器；对方不让下载的就在线播放（没网时放不了）。
  - 电脑上可以直接把文件拖到卡片或悬浮球上。
  - 歌单里每首歌右边的 ··· 可以改歌名、换封面、找歌词、删除。
  - 歌单右边的勾：当前这首在不在这个歌单里，点一下加入或移出。
  - 点歌单名字进去看歌，点歌就放。
  - 长按歌单名字：改名或删除。
- 右下歌词：卡片原地变成滚动歌词，点某一句跳到那里。放大镜可以在线搜歌词挑一个，铅笔可以粘贴或修改。
  - 导入 .lrc 时，文件名和歌名（或「歌手 - 歌名」）对得上就会自动配好。
  - mp3 里自带的封面和歌词会自动读出来。
- 右上声波：翻到背面。背面三行字都能直接点进去改，每个角色各存一套。

## 关于流行歌

流行歌来自第三方的 GD音乐台，不是各平台的官方接口，资源的版权归原平台和唱片公司。只供自己听，别拿去下载、传播或商用。这个源随时可能变动或停掉。

## 关于在线找歌的授权

在线找歌搜到的都是作者主动用 Creative Commons 等开放授权发布的音乐，个人听没有问题。每首歌的授权类型会记在歌单里（比如 CC BY-NC），作者名也会保留。如果你想把这些音乐用在别的地方（比如发视频），要按各自授权的要求署名，带 NC 的不能商用。

## 自动配歌词和封面

导入时会联网补全，找到的存进浏览器，之后离线也能看：

- 歌词来自 [LRCLIB](https://lrclib.net) 开放歌词库，优先挑带时间轴、时长对得上的版本。纯音乐会标成「纯音乐」。
- 封面来自苹果音乐的公开搜索，中文歌优先查台湾、香港区。

为了不配错：歌名和歌手都对得上才会自动用；没有歌手信息的歌不自动找封面。配错了可以在歌词页点放大镜手动挑，或者在歌单里点 ··· 换封面。

一次导很多首时，歌词库可能会让我们慢一点，插件会自动停下。过几分钟去扩展设置里点「补全缺的歌词和封面」就行。这两项都可以在扩展设置里关掉。

## 快速回复按钮

在快速回复里新建一个按钮，内容填：

```
/musicball
```

点一下藏球，再点一下出来。也可以分成两个按钮：`/musicball hide` 和 `/musicball show`。
就算关掉了 QR，扩展设置面板里也有「显示悬浮球」的开关。

## 存储说明

歌、封面、歌词都存在当前浏览器的 IndexedDB 里，不占酒馆服务器空间。

- 清除浏览器数据会把歌一起清掉。
- 换设备、换浏览器，歌不会跟过去。
- 扩展设置里有「导出 / 导入」备份，建议隔一阵导出一份。

iPhone 上的 Safari 在锁屏后可能会停止播放，这是系统对网页的限制。
