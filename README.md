# 共享耳机 · SillyTavern 音乐播放器

悬浮球音乐播放器，还能让 char「听见」你在放的歌：歌的情绪和意象会被悄悄化进正文，剧情情绪不对时 char 还会帮你换一首。

需要 SillyTavern 1.12 或更新的版本。

## 安装

**方法一：粘贴地址安装（推荐）**

在酒馆扩展面板点「安装扩展」，粘贴：

```
https://github.com/Bvli1-15/SharedEarphones
```

以后有新版，在「管理扩展」里点更新就行。跑酒馆的机器需要装有 git（Termux 里没有的话执行 `pkg install git`）。

**方法二：手动放文件夹**

1. 把仓库下载下来，得到 `SharedEarphones` 文件夹。
2. 放到 `SillyTavern/data/default-user/extensions/` 下面（多用户的话把 `default-user` 换成你的用户名）。
   - 手机 Termux 一般是 `~/SillyTavern/data/default-user/extensions/`。
3. 刷新酒馆页面。扩展面板里会出现「共享耳机」。

## 用法

- 点悬浮球：卡片弹出来；再点一下收回。球可以拖到任何地方，松手会记住位置。
- 卡片在屏幕正中间。按住卡片的空白处（封面、歌名一带）可以上下拖，最高到酒馆顶栏下面，松手会记住位置。
- 想只留卡片：先打开卡片，再在扩展设置里关掉「显示悬浮球」。关球不会自动弹出卡片，只是不会把开着的卡片关掉；刷新后卡片照原样留着。
- 左下星星：歌单。导入歌曲、导入歌词、切换播放模式、新建歌单都在这里。
  - 导入歌曲有五种方式：
    - **流行歌**：按歌名、歌手搜网易云等平台的歌（来自 GD音乐台），点 ＋ 加进歌库。只在线播放，不下载、不存音频，每次放的时候现取链接，所以没网时放不了。网易云搜不到的（比如周杰伦）可以点上面换成 JOOX 试试。对方限制 5 分钟 50 次请求，插件会自己数着。
    - **在线找歌**：搜开放授权的免费音乐（来自 Openverse，大多是 Jamendo 上独立音乐人的作品），能先试听，点 ＋ 收进歌库。曲库是英文的，搜索框下面有一排中文情绪词（钢琴、雨天、爵士、夜晚……）可以直接点。
    - **选文件**：可以多选。mp3、m4a、flac、wav、ogg/opus 都能读出歌名、歌手、封面；视频文件只取声音；把 .lrc 一起选上会自动配到同名的歌。
    - **压缩包**：整个文件夹打成 zip 一次导入，Windows 打的中文文件名也能认。
    - **粘贴链接**：音频文件的直链，一行一个。能下载的存进浏览器；对方不让下载的就在线播放（没网时放不了）。
      - 网易云的歌曲链接（包括会员歌的外链）也能直接粘，会像流行歌一样在线播放。App 里「分享 → 复制链接」得到的是短链接，要把那整段分享文字一起粘进来，插件靠里面的歌名去找。
      - 放不了的会说原因：文件已经不在了、对方不让访问、打开是网页不是音频，等等。
  - 电脑上可以直接把文件拖到卡片或悬浮球上。
  - 歌单里每首歌右边的铅笔按钮可以改歌名、换封面、找歌词、删除；有氛围分析的歌还会多一个「分析给 char 看」开关。
  - 歌单右边的勾：当前这首在不在这个歌单里，点一下加入或移出。正在放的歌单前面有 ♪，下面写着「正在播放」。
  - 点歌单名字进去看歌，点歌就放。
  - 长按歌单名字：改名或删除。
- 右下歌词：卡片原地变成滚动歌词，点某一句跳到那里。放大镜可以在线搜歌词挑一个，铅笔可以粘贴或修改。
  - 导入 .lrc 时，文件名和歌名（或「歌手 - 歌名」）对得上就会自动配好。
  - mp3 里自带的封面和歌词会自动读出来。
- 右上声波：翻到背面。背面三行字都能直接点进去改，每个角色各存一套。
  - 背面右上角点一下翻回正面；点耳机线中间的分叉是播放 / 暂停。这两个地方没有画按钮。

## 让 char 听见

所有开关都在扩展设置面板的「让 char 听见」一栏，悬浮窗里不放任何开关。

- **总开关**：在「让 char 听见」标题右边。打开后把正在放的歌告诉 char，只在播放时生效，暂停就不告诉。char 会结合当前情节，把歌的情绪和意象化进正文的语气、节奏、环境和心境里。插件会要求它用自己的话写，不照搬歌词，也不提到「你在听歌」这件事。
- **给模型看什么**：
  - 只给氛围：歌名和氛围标签，每轮约 40 token。
  - 氛围 + 正在唱的几句：默认，能接住此刻的歌词意象，每轮约 80 token。
  - 氛围 + 整首歌词：每轮几百到上千 token。
- **氛围标签怎么来**：导入时插件先在浏览器里把整首歌「听」一遍，这一步不花 token：速度、节拍清不清楚、音符疏密、响度和起伏、明暗、高中低频分布、声场宽窄、大概的调性（大调 / 小调）、整首的强弱走向（哪里轻、哪里推上去、结尾怎么收）。流行歌和在线播放的歌会试着临时下载一份来听，只用来分析、不存；对方不让网页读取时就听不到。然后二选一：
  - 规则换算：零 token，只看得出快慢明暗。
  - 共享耳机 API 判断：用一个只给这个插件用的接口，按「分析提示词」先写一段氛围分析（情绪色彩、能量、空间质感、节奏、音色、和声、结构、联想画面、身体感受、总结十个维度），再提炼出标签和情绪，每首歌只花一次。
- **共享耳机 API**：在「让 char 听见」一栏，有自己的开关。填接口地址、Key、模型名（OpenAI 兼容的接口都行，比如 DeepSeek、各种中转）。「获取模型」拉到列表后，在下面的下拉框里选；也可以直接手打模型名。「测试」可以试连。请求由酒馆服务器转发，不受浏览器跨域限制；Key 存在酒馆的设置文件里。
  - 不会借酒馆的主 API。开关关着或没填好时，导入的歌先不打标签，会弹窗提醒你可以在歌单里点铅笔手动添加。
  - 分析提示词可以在设置里改，「恢复默认提示词」能改回来。歌名、歌词、本地测的速度明暗和输出格式插件会自动加，提示词里不用写。
  - 模型本身听不到音频，插件会把本地测出来的声音特征当作它的「耳朵」一起发过去，再加上歌名、歌手、整首歌词和时长。它认识的歌会写得更具体；本地也没测到的维度会写「不明显」。
  - 升级后想让旧歌也用上新的声音特征，点「重新生成全部标签」，会先重新听一遍再写。
  - 快速回复里可以用 `/musicapi` 切换开关，`/musicapi on` 打开，`/musicapi off` 关上。
- **氛围分析**：存在每首歌里，歌单里点铅笔 →「改歌名」可以看和改。点铅笔后出现的「分析给 char 看」是每首歌自己的开关，打开后放这首歌时分析也会给 char，每轮多几百到上千 token；默认关着，只给标签。
  - 想把已有的标签按新方式重写一遍，点「重新生成全部标签」，手动改过的不会动。
  - 流行歌不存音频，本地会试着临时下载来听；对方不让读取时就听不到，这时选规则换算的话流行歌没有标签，可以手动填。
- **char 根据剧情换歌**：正文情绪和正在放的歌明显不搭时，char 会在回复末尾留一个隐藏标记，插件看到就换一首情绪合适的歌，再把标记从正文里删掉。换过之后会冷却几轮，冷却轮数可以设置。

标签和情绪可以在歌单里点铅笔 →「改歌名」手动改，手动改过的不会被自动覆盖。背面的音符也会跟着每首歌自己的速度流。

模型偶尔还是可能不听话提到音乐，这个没法百分之百保证。

## 关于流行歌

流行歌来自第三方的 GD音乐台，不是各平台的官方接口，资源的版权归原平台和唱片公司。只供自己听，别拿去下载、传播或商用。这个源随时可能变动或停掉。

## 关于在线找歌的授权

在线找歌搜到的都是作者主动用 Creative Commons 等开放授权发布的音乐，个人听没有问题。每首歌的授权类型会记在歌单里（比如 CC BY-NC），作者名也会保留。如果你想把这些音乐用在别的地方（比如发视频），要按各自授权的要求署名，带 NC 的不能商用。

## 自动配歌词和封面

导入时会联网补全，找到的存进浏览器，之后离线也能看：

- 歌词来自 [LRCLIB](https://lrclib.net) 开放歌词库，优先挑带时间轴、时长对得上的版本。纯音乐会标成「纯音乐」。
- 封面来自苹果音乐的公开搜索，中文歌优先查台湾、香港区。

为了不配错：歌名和歌手都对得上才会自动用；没有歌手信息的歌不自动找封面。配错了可以在歌词页点放大镜手动挑，或者在歌单里点铅笔换封面。

一次导很多首时，歌词库可能会让我们慢一点，插件会自动停下。过几分钟去扩展设置里点「补全缺的歌词和封面」就行。这两项都可以在扩展设置里关掉。

## 快速回复按钮

在快速回复里新建一个按钮，内容填：

```
/musicball
```

点一下藏球，再点一下出来（藏球不会关掉已经打开的卡片）。也可以分成两个按钮：`/musicball hide` 和 `/musicball show`。
就算关掉了 QR，扩展设置面板里也有「显示悬浮球」的开关。

## 存储说明

歌、封面、歌词都存在当前浏览器的 IndexedDB 里，不占酒馆服务器空间。

- 清除浏览器数据会把歌一起清掉。
- 换设备、换浏览器，歌不会跟过去。
- 扩展设置里有「导出 / 导入」备份，建议隔一阵导出一份。

iPhone 上的 Safari 在锁屏后可能会停止播放，这是系统对网页的限制。
